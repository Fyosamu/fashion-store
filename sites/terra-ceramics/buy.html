FAQ

Before you buy

Do I need WordPress or Elementor?

No. It is plain HTML, CSS and JavaScript — it runs on any host, including GitHub Pages. You can also lift the markup into Elementor HTML widgets.

Can I change the brand and colours?

Yes. The brand name is in the HTML, the palette is six variables at the top of style.css. Change them and the whole site re-skins.

Can I use it for client work?

Yes — MIT licence on the code and CC0 on the photographs. Resell it inside your own builds.

How fast is delivery?

Payments are verified on-chain, so the link is normally sent within a few hours.

What if I pay but get nothing?

Send the transaction hash again from the contact page — the hash is your proof and the file can always be re-sent.
