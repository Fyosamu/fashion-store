After purchase

Connect it in four steps

Everything ships in one zip. No plugins, no licence keys, no build tools — if you can paste text, you can install it.

01

Unzip the package

You get vera-kit.css, vera-kit.js, /images (20 photos), /widgets (16 HTML snippets), a 4-page working demo, README.md and INSTALL.md.

02

Upload the two files + photos

Put vera-kit.css, vera-kit.js and the photos into /wp-content/uploads/vera-kit/ — with the Media Library, or FTP if WordPress blocks those extensions.

03

Paste the loader once

In Elementor, add an HTML widget at the top of the page and paste these two lines (edit the URL to match where you uploaded):

<link rel="stylesheet" href="https://YOUR-SITE.com/wp-content/uploads/vera-kit/vera-kit.css" /> <script src="https://YOUR-SITE.com/wp-content/uploads/vera-kit/vera-kit.js" defer></script>
04

Paste the section widgets

One HTML widget per section — header, hero, marquee, categories, products, footer, bag. Set the page to Elementor Full Width and leave the containers with no padding: the kit controls its own spacing.

Elementor Pro? Add the same two lines once under Elementor → Custom Code (head + body end, whole site) and you can skip the loader widget on every page. The full guide — 3 installation methods, how to swap the photos for your own, how to change the price and email, plus a troubleshooting table — is in INSTALL.md inside the zip. Typical time: under 5 minutes.

FAQ

Before you buy

Do I need to know how to code?

No. You copy and paste: one loader widget, then one HTML widget per section. The full guide with the exact snippets is in INSTALL.md, and the typical setup takes under five minutes.

Do I need WooCommerce or paid add-ons?

No. The kit ships with a lightweight vanilla-JS cart that stores the basket in the browser and opens the visitor's email app on checkout. You can point it at any form endpoint instead.

Does it work with Elementor Free?

Yes. The HTML-widget method needs nothing but Elementor Free. Pro is only useful if you want to add the CSS and JS once for the whole site via Custom Code.

Can I use it on client projects?

Yes. The code is MIT licensed and the 20 photographs are CC0 — commercial use, no attribution, resell it inside your own builds.

How fast is delivery?

Payments are verified on-chain manually, so the link is normally sent within a few hours. Every order is checked before the file goes out.

What if I pay but receive nothing?

Send the transaction hash again from the contact page — the hash is your proof and the file can always be re-sent.
